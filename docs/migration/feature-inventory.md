## Missing or uncertain behavior

- `Alacrity/` has no source or project files in this checkout; it is an empty nested Git repository, not an existing plugin platform.
- No automated tests, snapshot tests, benchmark project, signature manifest, installer, updater, uninstall flow, plugin manifest, or policy verifier was found in the repository listing.
- The current generated artifacts (`Terraria.ChatEnhanced.exe`, `VanillaChatEnhancer.dll`, and INI files) are runtime/build outputs and should not be treated as source ownership boundaries.
- The current helper contains several historical features and compatibility fallbacks in one file. Exact default values and user-observed behavior must be captured before extraction.
